# 修整流程

用户指出某段错拍，先生成同时间段 A/B 对比，查旋律与低音的 note-on、note-off、速度图和相对重音，再决定修正。原曲时间 25 秒的段落始终从源文件 25 秒定位。

| 症状 | 要检查的证据 | 合理修正 |
|---|---|---|
| 左手切分变成每拍根音 | 低音/伴奏源起音与 MIDI 起音 | 恢复实际离拍起音，去掉无源支持的补拍 |
| 重音方向错 | 源声部 RMS、频谱与主次关系 | 在拍位正确后调整对应音符或声部力度 |
| 低音过高/发薄 | 基音与第二泛音，独立低音估计 | 有证据时纠正八度，不全轨机械下降 |
| 旋律变成高音装饰 | 稳定基频、声部上下文、候选冲突 | 更换主旋律候选，不单纯取最高音 |
| 试听漏音而 MIDI 有音 | SF2 琴键/力度 zone、各声道 program | 换连续覆盖音色并初始化所有声道 |
| 连音断裂/同音多敲 | 窗口 tie、真实起音、MIDI 事件顺序 | 合并无新起音片段；重复音先 NoteOff 后 NoteOn |

run 的 --melody-offset、--harmony-offset、--rhythm-offset、--bass-offset 是全层力度偏移，只适合声部平衡；它们不会修正错拍。--tempo 仅改变输出速度元数据，原曲音符秒数仍保持，不会修复转录起音错误。

根据问题选择重新开始的阶段：

- decode：源解码或映射错误。
- separate：串音明显或分离源错误。
- analyse：需要重新取基频、起音、独立音高或拍点证据。
- transcribe：更换模型、角色设置或检查持续音转录。
- export：已有转录和证据有效，只调整编配选择或力度、音色。

原版脚本没有逐音图形编辑器。要有依据地修改候选阈值或逐音编辑时，保留前版和审计记录，在任务工作副本修改并重做后续输出与验证。不能先交付一个未重新合成的 MIDI，再让 MP3 保持旧版却称为同一版。

修整后复查目标段，也检查全曲没有新产生的同音冲突、声部缺失、速度漂移或音色漏响。交付解释具体修正和还未确定的部分，不承诺模型无法保证的完全还原。
